这是怎么在浏览器里跑的？

  1. playground/ 是 pkgtype(kind: "foreign_library") 的 MoonBit 包，用 #export_name 导出 7 个非 raise 函数。
  2. moon build --target js --release playground 生成 playground.js；页面直接 import 调用。
  3. 字典、输入法、消歧、双拼全部打包进同一份产物，页面无网络请求、无后端。
  4. 行为由 326×4 测试、覆盖率 94.2%、14 个变异点与 CI 门禁守护。
