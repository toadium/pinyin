Capabilities

一个模块，十三条能力线

包间线性依赖、职责单一，core 与 data 零依赖，四个后端（wasm / wasm-gc / js / native）行为一致。

01

汉字 → 拼音

词句级转换，支持带调、数字调、无调、首字母四种格式与自定义分隔符。

convert 02

拼音 → 汉字

反向查找内置 20903 条单字与 843 条词组，三种声调格式互查。

reverse 03

多音字消歧

Viterbi + 带调 bigram 上下文决策，47,110 条词组最大匹配，常用多音词准确率 99.5%（基线 68.0%）。

disambiguate 04

拼音分词

Trie + 动态规划枚举全切分并取最优路径，处理 xian 这类歧义串。

segment 05

模糊匹配

zh↔z、ch↔c、sh↔s、n↔l、in↔ing 等 9 组规则，BFS 扩展候选。

fuzzy 06

搜索索引

倒排索引支持首字母、连续拼音与模糊拼音检索，面向中文文本搜索。

search 07

声调变调

三声、一、不、七、八五类变调规则，含同音字守卫避免误伤原调。

tone 08

规范化与编辑距离

统一大小写、ü/v 与声调格式；音节级 Levenshtein 与模糊距离。

normalize 09

N-gram 语言模型

Unigram / Bigram / Trigram 频率表，Laplace、Katz 回退与插值平滑、困惑度。

lm 10

输入法引擎

Beam Search + LM 评分，全切分候选、词组优先、用户词库与选择学习。

input 11

双拼输入

小鹤 / 自然码双拼 ↔ 全拼双向转换，已接入输入法候选流程。

shuangpin 12

流式处理

逐字符 feed / flush / reset，适合输入框实时标注与增量输出。

Get started

三分钟接入

标准 MoonBit 模块，无运行时依赖；浏览器端把 playground 包编译成一份 JS 即可复用同一实现。

安装 
moon add walkzzz/pinyin@0.8.0
本地端到端演示 
moon run demo --target native
工程门禁 
moon check --target all --warn-list +73 --deny-warn
moon test  --target all --warn-list +73 --deny-warn
node scripts/check_coverage.mjs
node scripts/mutation_test.mjs
node scripts/check_pages.mjs
汉字 → 拼音 
let py = @convert.PinyinHelper::convert_to_pinyin_string(
  "我是中国人",
  " ",
)
// wǒ shì zhōng guó rén
输入法候选 
let engine = @input.PinyinInputEngine::new()
let candidates = engine.input("nihao")
// candidates[0].text == "你好"
多音字消歧 
let tones = @disambiguate.PinyinDisambiguator::disambiguate(
  "银行行长",
)
// ["yin2", "hang2", "hang2", "zhang3"]
浏览器端复用： playground 是 pkgtype(kind: "foreign_library") 的 MoonBit 包， 用 #export_name 导出 17 个函数，moon build --target js --release playground 生成 playground.js；页面直接 import 调用，无需 HTTP 服务。

已知边界：不提供中文分词、语音合成/识别与方言拼音；N-gram 模型基于内置字典， 不支持外部语料训练。

Under the hood

这个页面是怎么跑的

  1. 1

    playground/ 是 MoonBit 包，用 #export_name 导出转换、繁简、自定义字典、多音集合、通用拼音、消歧、输入法、双拼、分词、规范化、版本共 17 个非 raise 函数。

  2. 2

    moon build --target js --release playground 产出 playground.js，字典与算法一并打包。

  3. 3

    页面通过 ES module 直接 import 该产物，所有计算留在浏览器，不调用后端服务。

  4. 4

    行为由 328×4 测试、94.2% 覆盖率、14 个变异点、文档与页面自检持续守护。
